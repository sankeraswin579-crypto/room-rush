# Room Rush

A room-code trivia game for 2–20 players. Host a room, share its four-character code, and play from any browser. Correct answers score 100 points.

## Run

Requires Node.js 18 or newer. Run `npm start`, then open http://localhost:3000.

To play over Wi-Fi, share the host computer's local network address. For a public link, deploy this folder to a Node hosting service. Rooms are stored in memory and reset when the server restarts; multi-instance hosting needs sticky routing or shared storage.
